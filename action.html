After the record

If the patch is not the cure, the next ask has to name the wound.

A board comment that only says “stop cutting” will be answered with the deficit slide. A comment that cites the allotment gap, the recapture line, the TAP-vs-closure math, and a campus timestamp is harder to file away. This page is a checklist, not a campaign script.

A feed is not a bond

Sharing a chart is not the same as sitting next to someone whose kid lost a bus stop. The state can recapture hundreds of millions while a local contract still reimburses rental cars. Neither yields if the only civic habit left is doomscrolling the outrage and closing the tab.

What does not substitute

A website, including this one — even one drafted with AI. A nickname for the superintendent. A private group chat that never becomes a timestamped question. Those can start a thought. They do not audit a contract or move Chapter 49.

What still has a chance

Show up with the table: recapture $715.5M adopted; allotment $6,160 + $55; superintendent base $362,250 plus $36,750 retirement and reimbursed travel including a rental car; ~$60M one-time property monetization; librarian line under $1M. Ask that those lines be in the same packet as class size. Repeat the next month.

A usable three-line comment

1. State the record (allotment $6,160 + $55; recapture $715.5M adopted; librarian line on fund balance).

2. Ask one why (Why do TAP costs consume closure savings? Why no ADA model for hubs?).

3. Name the goal: time and a sane class load for the teacher who has to ready the child — not another shuffle in June.
