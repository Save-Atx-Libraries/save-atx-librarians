# How this book is made

Each chapter is one meeting in the Desktop caption folder, in **meeting date** order (not download date).

Source files: auto-captions (`.srt` / `.vtt`). Overlapping YouTube lines were collapsed so the text can be read once; the original files remain in `meetings/transcripts/`.

This is not a skim of eight board nights. Campus meetings are chapters. Spanish tracks of the same night are noted, not treated as a second vote.

GitHub login is parked until you say to start it.
